# 三組對照案例：固定兩維，只改變一維

狀態：教學與試辦規格，六項任務均尚未進行真實企業實測。

## X 組：客服配送政策回覆

固定 Y 每天執行、Z 低推理；相同題型與回覆標準。

| 項目 | X-A 已知程度高 | X-B 已知程度低 |
|---|---|---|
| 輸入 | 題目及直接附上的適用核定政策 | 同難度題目及包含適用政策的指定文件集 |
| 執行 | 擷取政策，寫回覆草稿 | 限定來源查找，核對日期，寫草稿 |
| 輸出 | 回覆、引用段落 | 回覆、來源、日期及引用段落 |
| 人機分工 | 人提供政策，AI 整理，人抽查 | 人限定來源，AI 查證，找不到轉人工 |
| 成本控制 | 生成與覆核上限 | 額外設定查找時間與文件上限 |

共同驗收：答案符合政策、引用可回查、無新增承諾。缺少政策就報缺口。試辦材料以虛構公司及已核定政策建立，不能加入政策衝突或例外裁決，避免改變 Z。
VAC 步驟：檢查輸入 → 查找或讀取 → 整理 → 核對 → 交付草稿。
觀察：查找時間、覆核時間、轉人工率、品質及總投入。X-B 若因文件過難增加推理要求，須重設配對，不得宣稱單維對照成立。

## Y 組：訂單與收款核對

固定 X 高、Z 低；相同欄位與比對規則，每批 100 筆。

| 項目 | Y-A 一次性 | Y-B 每天重複 |
|---|---|---|
| 輸入 | 活動訂單及收款紀錄一批 | 相同格式每日一批，期間三個月 |
| 執行 | 人啟動批次核對 | 評估排程、日誌、例外通知 |
| 輸出 | 差異清單與總額 | 每日差異清單、總額及執行紀錄 |
| 人機分工 | 人交檔，程式核對，人確認 | 人維護規則，流程重複執行，人處理例外 |
| 成本控制 | 本次設定與覆核投入 | 建置、運作、維護分開記錄 |

共同驗收：金額正確、差異可追溯；Y-B 增驗漏檔、重複檔及失敗回報。不能因高頻而改變單批筆數或規則難度。
VAC 步驟：驗證欄位 → 核對訂單與收款 → 列差異 → 核對總額 → 保存成果。
觀察：期間總投入、合格批數、單批成本、例外工時。教學可用多日模擬資料演練，但模擬執行不能宣稱三個月營運驗證。

## Z 組：每週補貨建議

固定 X 高、Y 每週一次；同一份已核對庫存、需求、交期、價格及採購限制資料。

| 項目 | Z-A 低推理 | Z-B 高推理 |
|---|---|---|
| 輸入 | 資料及核定安全庫存公式 | 相同資料及已明確的優先目標與限制 |
| 執行 | 代入公式逐項計算 | 比較符合預算、交期與最低訂量的組合 |
| 輸出 | 補貨量及計算明細 | 可行方案、約束檢查與取捨理由 |
| 人機分工 | 程式計算，人抽查 | 工具分析，AI 說明，主管核決 |
| 成本控制 | 計算與抽查上限 | 分析時間、情境數及修訂上限 |

共同驗收：資料與計算正確。A 檢查公式；B 檢查所有硬性限制，無可行解必須明說。不得添加未知市場研究或新供應商探索，避免改變 X。
VAC 步驟：核對資料 → 計算／比較 → 檢查限制 → 輸出明細 → 人工核定。
觀察：分析時間、覆核工時、可行性與返工。兩項任務驗收要求不同，不宜把完成時間差直接當作模型性能優劣。

## 共通紀錄

每組先凍結材料、標籤、門檻與候選路由，再執行。記錄模型／工具版本、人員、期間、順序及資料差異。完成紀錄不等於取得因果證據。
