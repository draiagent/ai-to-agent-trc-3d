# 交接與任務總成本

## 交接契約

TRC-3D 交付任務目標、X/Y/Z 診斷及證據、候選方案、選擇理由、人工責任、品質／時間／風險／預算限制。
VAD 將其轉為角色、流程、工具、權限及例外路徑。
VAC 固定輸入、步驟、輸出、驗收、執行上限、停止及轉人工條件。
執行後將實際投入、失敗原因及驗收結果回饋下次診斷；不得把停止當完成。

## 四項控制能力

- 可預估：事前核定期間、幣別、預算、工時與完成標準。
- 可監控：追蹤模型／工具費、人工分鐘、重試及進度。
- 可調整：達預警門檻時縮小範圍、切換方案或轉人工；達停止門檻時停止。
- 可驗收：核對可追溯成果與實際總投入。

## 記帳原則

任務總成本可包含建置、AI／工具、人工、維護及可明確估值的其他項目。每筆支出只計一次；人工覆核及返工以活動標籤記錄，不再加總成另一筆相同成本。
人力成本＝工時×核定時薪。等待時間另列，不任意換算成錢。風險以獨立限制管理，只有估值有根據時才另列期望損失，並揭露假設。
比較一次性與重複任務時，同時報告觀察期間總成本、完成件數與每件合格成果成本，明列建置攤提方式；不得只比較 API 單價。

## 任務完成判定

品質合格、時間在限、風險在限、總投入在核定範圍內，且有成果證據。預算超限即使成果合格，也不能記成「成本控制通過」。經批准調整預算時保留原始及修訂版本，不能事後無痕提高門檻。
