# 驗證與反證方案

研究問題：三維診斷是否有助於選擇可達成品質、期限、風險及預算要求的協作方式？

1. 事前登錄任務、三維定義、對照條件、候選路由、替代方案、品質門檻、預算、期限、失敗條件與試驗次數。
2. 由兩位評估者獨立標記 X/Y/Z，記錄一致與不一致處；不得事後為符合結果改標籤。
3. 三組單維對照檢驗任務條件改變後的路由差異。另在同一任務比較推薦與替代路由，才可檢驗路由效益。
4. 固定共同資料難度、工具版本、計價、人員與順序影響；可行時交錯執行，記錄不可控制差異。
5. 使用未參與規則設計的新任務，保留成功、失敗與中止，不只挑選成功案例。

| 判定 | 條件 |
|---|---|
| 支持 | 達成事前門檻，且符合已登錄的路由效果預測 |
| 部分支持 | 部分預測成立，但有門檻未達或不確定性 |
| 反例 | 推薦方案違反事前完成／成本約束，而可比替代方案達標；或出現事前指定反例 |
| 無法判定 | 資料不足、兩維未固定、環境變更或重大混雜 |

一次反例應修正對應規則或適用範圍，不直接宣稱整套方法論失效。反之一次成功也不構成普遍有效。檢查成本可控性不等於要求最低成本。

本版只提供驗證規格，沒有執行結果。門檻及樣本數須事前依任務訂定，不在看到結果後調整。
